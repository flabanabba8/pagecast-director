## 0.4.0 - ask the user which voice; never pick one (2026-11-12)

- New `pagecast_speech_setup`: finds what this computer has (installed speech programs, speech servers that answer, which online accounts are set up), reads the hardware (OS, RAM, GPU memory) and returns the options plus questions for the agent to ask the user (what they want to make, natural vs plain voice, whether online and paid use is OK and a budget, what they already have, and WHICH route they want). The route the user picks is saved and used; nothing is chosen for them. Rendering and `engine: chosen` casting return the options and questions until a route has been chosen (a person in the dashboard is not gated). A "no online services" answer blocks online engines even when named; the budget caps the Gemini spend guard.
- Suggestions shown with the options (never a decision): online services in the order Gemini 3.8 Flash TTS, Inworld, ElevenLabs with each one's free allowance, price, source link and the date it was verified; local models that fit the detected hardware (Higgs TTS 3, Qwen3-TTS, Orpheus, Kokoro, Pocket TTS, Kitten, Piper, espeak-ng, Flite and others) with licence, cloning, how to run and whether this plugin can use it. New wiki page `llmwiki/speech-models.md` and `speech_catalog.json` (51 local models and 13 local servers/runtimes, from vendor pages, model cards, READMEs and issue trackers read on 2026-11-12;). Each VRAM figure says whether it is stated, user-reported or an estimate. The server list includes Ollama and llama.cpp, which gained OpenAI-style speech endpoints in October 2026 and were read from their docs only, not run.
- New engine `system` (installed programs: espeak-ng, flite, Piper with a model, macOS `say`, Windows speech). New engine value `chosen` for `pagecast_voice`: the route saved by the user. The default narrator for a new book stays the old Flite placeholder and is not a choice.
- Knowledge freshness: the setup tool reports whether its built-in speech knowledge looks out of date (checked more than 30 days ago, or a known deadline such as Gemini's promotional pricing ending 2026-12-31 has passed) and, if so, tells the user and ASKS whether to research the current facts online; nothing is researched without their yes. Approved research is saved as dated overrides (`knowledge_updates`), never into the shipped catalog. Tested with fixtures; the research step itself is the host agent's and was not run here.
- Tested here: 110 Python tests; a real offline render through the `system` engine (flite) with a WAV check; loopback-only probing with no redirects; hardware parsing with fixtures and on this machine. NOT tested here: macOS `say`, Windows speech, Piper, a live hosted request, the free-tier figures themselves (read from vendor pages, not exercised), any local model other than Flite.
